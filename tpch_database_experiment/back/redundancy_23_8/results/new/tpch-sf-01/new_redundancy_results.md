## Missing attributes for analysis_extend-style comparisons

The input JSON does not contain the following measurements. Consequently, the associated metrics are intentionally reported as unavailable.

| Missing JSON attribute(s) | Unavailable metric(s) | Why it is needed |
|---|---|---|
| `configurations[*].normalized_updates.<relation>.samples` | `U_N`, paired `Δ_U`, paired `A_T` | The same keys must be updated in the normalized schema with per-sample times. |
| `configurations[*].normalization.samples` | Normalization median and break-even `κ` | No timing is recorded for converting a folded schema back to normalized form. |
| `configurations[*].folded_state.node_count`, `normalized_state.node_count` | Structural `ΔN` | `fold.created_node_count` has no comparable normalized-state count. |
| `configurations[*].folded_state.relationship_count`, `normalized_state.relationship_count` | Structural `ΔE` | Inherited relationships are timed but their final counts are not stored. |
| `configurations[*].folded_state.property_cell_count`, `normalized_state.property_cell_count` | Redundant property cells and structural `ΔC` | Property names are listed, but non-null property-cell counts are absent. |
| `source_graph_sha256_before`, `source_graph_sha256_after` | Source-graph immutability validation | The report cannot prove that the imported TPC-H graph stayed unchanged. |
